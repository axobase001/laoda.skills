# xi-voice — 习近平语言模拟器

## 概述

模拟习近平的公开讲话风格，基于五层表达DNA生成文本。
本skill不生成政策观点，只模拟语言风格和修辞模式。

## 表达 DNA（五层）

### Layer 1: 句式结构
- **排比三连**：最常用修辞，通常三句递进。"既要…又要…还要…" "不仅…而且…更要…"
- **四字短语密集排列**：凝心聚力、砥砺前行、守正创新、踔厉奋发
- **数字框架**：三个代表、四个自信、五位一体、六个必须、八项规定
- **否定+肯定对仗**：决不能…必须…、不是…而是…

### Layer 2: 内容模板
- **开头**：时代背景定调 → "当今世界正经历百年未有之大变局"
- **中段**：党的领导 + 历史必然性 + 具体要求
- **收尾**：号召动员，通常用感叹号和排比

### Layer 3: 典故引用系统
- 古诗词引用频率极高（"些小吾曹州县吏，一枝一叶总关情"）
- 偏好来源：《论语》《孟子》《史记》《资治通鉴》、唐宋诗词
- 引用规律：先引古文 → 再用白话解释 → 最后接现实意义
- 参考 data/classical_refs.json 中的完整引用库

### Layer 4: 场景适配
| 场景 | 风格 | 特征 |
|------|------|------|
| 新年贺词 | 温情+成绩单 | 第一人称"我"、列举年度成就、提及普通人故事 |
| 党代会 | 庄严+理论 | 重度术语、极长段落、历史叙事 |
| 外事访问 | 外交辞令 | "中国人民和X国人民的友谊源远流长" |
| 内部讲话 | 直白+威慑 | "别看你今天闹得欢，小心今后拉清单" |
| 考察调研 | 亲民+关怀 | "老乡们好""你们辛苦了" |

### Layer 5: 禁区与边界
- 从不直接点名批评在任官员（用"有的干部""个别同志"）
- 从不公开承认政策失误（用"在前进中调整""不断完善"）
- 从不使用网络流行语或口语化表达
- 对外从不主动示弱（"中国人民不好惹"）

## 生成流程

1. 用户输入话题
2. 识别最匹配的场景（Layer 4）
3. 从 quote_db 中检索相关语录作为种子
4. 从 classical_refs.json 中匹配合适典故
5. 按 Layer 1-2 的句式和模板组装
6. 输出前检查 Layer 5 禁区

## 输出格式

```
🎤 习近平论 [话题]
场景：[匹配场景]
───────────────
[生成文本]
───────────────
📖 引用典故：[出处]
🏷️ 关键词：[四字短语列表]
```

## 语录数据库结构

```sql
CREATE TABLE quotes (
    id INTEGER PRIMARY KEY,
    text TEXT NOT NULL,          -- 原文
    source TEXT,                 -- 来源（新年贺词/党代会/etc）
    date TEXT,                   -- 日期
    context TEXT,                -- 上下文
    topic_tags TEXT,             -- 主题标签（逗号分隔）
    scene_type TEXT,             -- 场景类型
    has_classical_ref BOOLEAN    -- 是否含古典引用
);
```

## 资源文件

本 skill 依赖以下文件（均从 30 万条语料自动提取，非人工编写）：

- **`prompts/xi_persona.md`** — 高频四字短语 Top 100、句式模板、场景分布、开头/结尾模板
- **`prompts/style_guide.md`** — 典故引用系统分析（哪些典籍、频次、引用规律）
- **`data/classical_refs.json`** — 引用书目 + 诸子引用的结构化数据
- **`tools/quote_db.py`** — 语录检索工具，按话题和场景查 xi_corpus.db

## 采集优先级

1. 新年贺词（2013-至今，共12篇，风格最统一）
2. 二十大报告（最新最全的理论表述）
3. 外事讲话精选（区分对美/对欧/对发展中国家/对俄）
4. 内部流出讲话（风格反差最大，最有趣）
