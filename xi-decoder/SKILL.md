# xi-decoder — 官方话语解码器

## 概述

中国官方话语是一套高度编码的信号系统。
同一个词在不同语境中含义完全不同。本skill将官方文本翻译为明文。

## 信号词典（核心资产）

### 升级信号（由弱到强）

| 官方表述 | 信号等级 | 翻译 |
|---------|---------|------|
| 表示关切 | 🟢 1级 | 注意到了，还没打算动 |
| 强烈不满 | 🟡 2级 | 开始认真了 |
| 严正交涉 | 🟡 3级 | 正式警告 |
| 坚决反对 | 🟠 4级 | 会有具体反制 |
| 不惜一切代价 | 🔴 5级 | 准备动真格 |
| 勿谓言之不预 | 🔴 6级 | 历史上这句话出现后都打了（1962印度、1979越南） |

### 退让信号（由弱到强）

| 官方表述 | 实际含义 |
|---------|---------|
| 在前进中不断完善 | 政策出了问题，在调整 |
| 因时因势优化调整 | 原来的搞不下去了 |
| 实事求是 | 要换方向了 |
| 不折腾 | 之前折腾过头了 |
| 稳中求进 | 先别动了 |

### 人事信号

| 官方表述 | 实际含义 |
|---------|---------|
| 另有任用 | 平调或明升暗降 |
| 因个人原因辞职 | 被迫离开 |
| 严重违纪违法 | 要进秦城了 |
| 配合组织调查 | 已被控制 |
| 同志们 → 干部们 | 称呼变化暗示关系远近 |

### 经济信号

| 官方表述 | 实际含义 |
|---------|---------|
| 高质量发展 | GDP增速不重要了（或者说不好看了） |
| 新质生产力 | 旧的增长模式不行了 |
| 供给侧结构性改革 | 要砍产能了 |
| 共同富裕 | 要动富人的蛋糕了 |
| 防止资本无序扩张 | 互联网大厂要挨整了 |
| 房住不炒 | 不救房地产（但可能会变） |
| 适度宽松 | 要放水了 |

### 外交信号

| 官方表述 | 实际含义 |
|---------|---------|
| 老朋友 | 关系好且有利用价值 |
| 合作伙伴 | 标准外交关系 |
| 伤害了中国人民的感情 | 标准抗议模板，力度不大 |
| 中方将采取一切必要措施 | 真的会动手 |
| 搬起石头砸自己的脚 | 我们认为对方会先撑不住 |
| 互利共赢 | 标准套话，无实际信号 |
| 不干涉内政 | 这个话题到此为止 |

## 语境解读规则

### Rule 1: 看谁说的
- 外交部发言人 → 标准操作，信号弱
- 国务委员/外长 → 正式警告
- 总书记亲自表态 → 最高级别信号
- 新华社/人民日报社论 → 政策风向标
- 环球时报 → 试探气球，不代表官方立场

### Rule 2: 看在哪说的
- 记者会例行回应 → 走流程
- 专门发声明 → 重视
- 约见大使 → 很重视
- 召回大使 → 极其严重
- 军事演习配合 → 最高级别

### Rule 3: 看说了几次
- 说一次 → 表个态
- 连续多天重复 → 在造势
- 突然不说了 → 要么已经解决，要么在准备更大动作

### Rule 4: 看新造的词
- 新华社/人民日报突然出现一个新提法 → 新政策信号
- 新词出现在总书记讲话中 → 已经是决定了
- 新词出现频率突然上升 → 大规模推行前奏

### Rule 5: 看删了什么
- 以前常说现在不说了 → 政策转向
- 报道突然消失 → 有人出事了
- 评论区关闭 → 舆论管控升级

## 解码流程

1. 用户输入官方文本
2. 分词 → 匹配信号词典
3. 识别说话人和发布渠道（Rule 1-2）
4. 检查重复频率和新旧词变化（Rule 3-5）
5. 交叉比对历史信号案例
6. 输出解码结果

## 数据建设优先级

1. **信号词典扩充**（最核心）
   - 目标：500+ 条信号词映射
   - 来源：外交部发言人数据库、新华社稿件、人民日报社论
   - 每条需要：官方表述、翻译、信号等级、使用场景、历史案例
   
2. **历史信号案例库**
   - 格式：信号词 + 发布时间 + 后续实际行动 + 间隔时间
   - 重点："勿谓言之不预"的所有历史使用及后果
   - 重点：所有"退让信号"及实际政策调整
   
3. **渠道权重标定**
   - 同样的话从不同渠道发出，含义完全不同
   - 需要标注每个渠道的历史可靠性
