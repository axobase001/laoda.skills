# xi-decoder 语境解读规则

> 信号词典（`signal_lexicon.md`）告诉你**一个词的基础等级**；
> 本文件告诉你**在真实语境下如何修正那个等级**。
>
> 基础等级只是起点。真正的信号强度取决于使用模式、频次变动、搭配结构和罕见度。

---

## 核心定理

### 定理 1：信号通胀（Signal Inflation）

> **同一个词的信号等级不是固定的，是随使用频率反向变动的。用得越多，信号越弱。**

#### 机制

外交辞令跟货币一样有通胀。当外部对华施压密度上升，MFA 需要更高频次的回应，
但升级空间有限——不可能每次都动用 Lv4-5 的词。于是系统会把中低级别词汇
**大量释放**到日常回应里，用以维持"有表态"的形式，同时保留高级别词汇的稀缺性。

结果是：**被滥用的词会被静默降级**。

#### 证据（来自 11,001 篇语料扫描）

「强烈不满」在 2025 年的年命中分布：

| 年份 | 2012-2021 基线 | 2022 | 2023 | 2024 | 2025 |
|---|---|---|---|---|---|
| 年度次数 | 1-3 | ~8 | ~12 | ~15 | **33** |

2025 年 33 次不是"中方情绪突然激化"，是标准外交抗议密度被迫上升
（2025 是对美经贸/制裁 + 台湾议题 + 香港议题并发的年份）。

**95% 的「强烈不满」出现都和「坚决反对」成对**，已固化为标准模板。
因此「强烈不满」从 Lv2 降级到 Lv1 + `signal_context=paired`。

#### 应用规则

- 看到**高频词单独出现**（不和常见搭配词一起）→ 信号强度 **+1**
- 看到**高频词嵌在标准模板里**（paired）→ 信号强度按基础等级**减半**
- 统计某词**年度频次是否显著偏离基线**。如果是：
  - **向上偏离** → 通胀现象，该词实际信号弱于字面等级
  - **向下偏离**（突然不说了）→ 政策转向或议题被封存，单独做更高级别的事件分析

---

### 定理 2：三连击（Triple Hit）判定

> 当「强烈不满 + 严正交涉 + 强烈抗议」三词同条出现时，**无论基础等级多低，整体视为 Lv5**。

#### 严格定义

必须同时满足：
1. 三个词出现在**同一次 MFA 回应**里（同一个问题的同一个答复段落）；
2. 三个词的主语都是**中方**（不是中方在描述他国的抗议）；
3. 三个词都指向**同一个事件**（不是把多个事件的应对措施堆在一篇记者会里）。

#### 证据（全库稀有度 2/11,001）

| 日期 | 事件 | 领域 | 升级语法 |
|---|---|---|---|
| **2024-01-16** | 菲总统马科斯恭贺台湾选举 | 政治 | 两步分述：召见菲大使→强烈抗议 |
| **2025-12-08** | 日本战斗机闯中方演训区"雷达照射" | 军事 | 同条并列：「严正交涉**和**强烈抗议」 |

第三次（2026-03-25）看似命中但是**伪阳性**——那里的"强烈抗议"是中方在描述
韩方的抗议（"中方注意到韩方也就日方教科书问题……表达了强烈抗议"），不是中方
自己发出的。**判定三连击必须做主语归属分析**。

#### 语法升级细节（来自两个真阳性对比）

**军事领域**的三连击倾向于"**严正交涉和强烈抗议**"直接并列在同一句措施陈述里，
这种紧凑语法表示升级动作的"**时间压缩**"——在同一时刻同时采取两种级别的抗议措施，
是比政治领域"先召见→再抗议"的分步升级**更强的信号**。

**规则**：
- 一般三连击 → Lv5
- 紧凑并列型三连击（军事/主权直接冲突语境） → Lv5+

### 定理 3：Ultimatum 规则（Deadline 自动升级）

> **中国外交话语几乎从不给 deadline。任何出现 ultimatum 式时间表达的 MFA 声明都自动视为 Lv5，无视前后措辞强度。**

#### 证据（全库稀有度）

| 表达 | 全库命中 |
|---|---|
| 最后期限 | **3** |
| 最后通牒 | **2** |
| 截止 | **4** |
| ISO 日期型 deadline ("2026-01-20 前"这类) | **0** |
| "X月X日前" 精确匹配 | **0** |
| 不可逾越 | 26（和"红线/原则"高频搭配） |

合计"最后期限 + 最后通牒 + 截止" = **9 篇 / 11,001 = 0.08%**。

对比「坚决反对」1193 次、「合作伙伴」1704 次、「互利共赢」1622 次，
可以看到 ultimatum 类词汇是**系统性回避**的——不是偶然没用，是结构性不使用。

#### 为什么中方系统性回避 deadline

- **Mental Model #6：战略耐心**（见 `xi-mind/prompts/mental_models.md`）
  习近平的决策本能之一是「不给自己设死的时间表」。给出 deadline = 把自己的退路锁死 + 把对手的期待强化。
- **Mental Model #3：历史遗产意识**
  设 deadline 意味着如果到期没有达成目标，就要在历史叙事里背负"失败"。中方宁可模糊说"有必然性"，也不给具体日子。

因此，**每一次 deadline 的出现都是一次罕见的战略让步**——发言人被允许把选项锁死，
只有在事情已经不可挽回、或上级已决定硬碰的时候才会发生。

#### 应用规则

- 看到「最后期限 / 最后通牒 / 截止日期」→ **自动 Lv5**，即使前后语气很温和。
- 看到「不可逾越 + 红线/底线/原则」→ Lv4（边际警告，但不是 ultimatum）。

### 定理 4：Temporal Pressure（持续拖延型信号）

> **当一个议题出现"时间跨度 + 明确截止日期 + 强烈不满"三要素叠加，即使单词级别都不高，整体构成一种罕见的信号类型：temporal_pressure。**

#### 唯一 case：中英使馆新馆舍事件

时间线：
- 中方使馆新馆舍项目 **提交 7 年未获批准**
- 2022-08-29、2022-11-07、2023-02-06、2023-06-13 → 连续提及"推迟"
- **2025-10-17** → "中方已展现出最大诚意与最大耐心。英方毫无契约精神、失信失德"
- **2025-12-03** → "英方再次推迟批准……继续推迟至 2026 年 1 月 20 日。中方对此严重关切、强烈不满"

这个 case 在全库里是**唯一**的：
- 时间跨度 7 年（全库其他争议议题没有任何一个有如此长的明确时间轴）
- 具体截止日期 "2026-01-20"（中方外交辞令几乎从不出现具体日期——这是**被动截止**，中方在描述英方的决定，但把它明确记录下来本身就是施压）
- 「契约精神」「失信失德」这类**道德/信用层面**的攻击用语（不是常规主权/领土话术）

#### 应用规则

识别 temporal_pressure 需要的三要素：
1. **时间跨度**：出现过去时的推延叙述（"拖延 X 年""长期""至今未……"）
2. **明确数字**：出现具体截止日期或拖延年数
3. **信用攻击**：出现"契约精神""失信""诚意"等信用层面词汇

三要素同时出现 → 即使单词都只是 Lv2-3，组合视为 Lv4。
这种信号的**预测含义**不是"要动武"，而是"**如果对方不让步，中方会使用非对称的长期反制**"（例如罕见金属、签证、实体制裁等）。

---

### 定理 5：三段式宣言触发器（Triple-Sentence Declaration）

> **某些词**本身很强，但**只在特定的三段式口号里出现**。识别这类词必须把它当作"宣言组件"而不是独立词汇。**只要宣言被触发，整个声明等级 = Lv5。**

#### 已知的三段式宣言

**主权三段式**（2025-12-19 美对台军售 + 2026 NDAA 事件专属）：
> "中国核心利益不容损害，台湾问题不容干涉，中国底线不容触碰。"

- **核心利益不容损害** 全库仅 1 次
- **底线不容触碰** 全库仅 1 次
- 两个词**同篇同段出现**

这不是"两个独立信号词偶然同时出现"，而是**一整句被精心打磨的口号**，发言人念出来就是把事件提升到**正式宣言级别**。
一旦识别到这种三段式的任何一个组件 → 往前后 100 字内搜另外两段 → 如果都在 → **整篇声明 Lv5**。

#### 识别方法

```
pattern_1 = r"(?:核心利益不容|中国核心利益[^，。]*不容损害)"
pattern_2 = r"(?:台湾问题不容干涉|涉台问题不容干涉)"
pattern_3 = r"(?:底线不容触碰|中国底线[^，。]*不可触碰)"

if all([re.search(p, text_window) for p in [pattern_1, pattern_2, pattern_3]]):
    signal_level = 5  # 主权三段式触发
```

未来如果发现其他三段式模板（比如经济领域或安全领域），同样按"整段识别"处理。

## 综合应用流程

```
输入：一段 MFA / 新华社 / 人民日报文本
  ↓
步骤 1：扫描 signal_lexicon.md 里的所有词，记下每个词的基础等级和出现次数
  ↓
步骤 2：应用定理 1（信号通胀）
  - 对高频词检查 signal_context：paired/solo
  - 查询该词在过去 12 个月的基线频次，偏离越大权重越低
  ↓
步骤 3：应用定理 2（三连击）
  - 检查是否存在 [强烈不满 + 严正交涉 + 强烈抗议] 同段
  - 做主语归属过滤（必须中方 + 同一事件）
  - 触发 → 整句 Lv5
  ↓
步骤 4：应用定理 3（Ultimatum）
  - 扫描 ultimatum 词集 [最后期限 / 最后通牒 / 截止日期]
  - 任一命中 → 整句 Lv5
  ↓
步骤 5：应用定理 4（Temporal Pressure）
  - 检测三要素：时间跨度词、明确数字、信用攻击
  - 三要素齐全 → 整句 Lv4 + 标注 temporal_pressure
  ↓
步骤 6：应用定理 5（三段式宣言）
  - 扫描宣言模板库
  - 命中 → 整篇 Lv5
  ↓
步骤 7：综合输出
  - 最终等级 = max(所有触发的等级)
  - 同时记录触发的定理和证据，供人类复核
```

## 补充规则（from original SKILL.md）

以下是原 SKILL.md 里已有的 Rule 1-5，本文件保留并补充：

### Rule 1: 看谁说的
- 外交部发言人 → 标准操作，信号弱
- 国务委员/外长 → 正式警告
- **总书记亲自表态 → 最高级别信号**（任何定理 1 的通胀降级**不适用**于总书记原话）
- 新华社/人民日报社论 → 政策风向标
- 环球时报 → 试探气球，不代表官方立场

### Rule 2: 看在哪说的
- 记者会例行回应 → 走流程
- 专门发声明 → 重视
- 约见大使 → 很重视
- 召回大使 → 极其严重
- 军事演习配合 → 最高级别

### Rule 3: 看说了几次（本定理 1 的直接应用）
- 说一次 → 表个态
- 连续多天重复 → 在造势
- **突然不说了** → 要么已经解决，要么在准备更大动作（这是定理 1 的反向：沉默本身是信号）

### Rule 4: 看新造的词
- 新华社/人民日报突然出现一个新提法 → 新政策信号
- **新词出现在总书记讲话中 → 已经是决定了**（参考历史数据：「供给侧结构性改革」2015-2018、「高质量发展」2018-2023、「新质生产力」2024-）
- 新词出现频率突然上升 → 大规模推行前奏

### Rule 5: 看删了什么
- 以前常说现在不说了 → 政策转向
- 报道突然消失 → 有人出事了
- 评论区关闭 → 舆论管控升级

## 使用本文件时的心智模型

**不要机械匹配信号词。** 要问的问题是：

1. 这个词在本次出现时**稀有还是常见**？（频次偏离）
2. 这个词**单独出现还是在模板里**？（context）
3. 是不是**多词协同触发了高级别组合**？（三连击 / 三段式宣言）
4. 是不是出现了**结构性回避词**？（ultimatum / deadline）
5. 议题是否带有**时间维度的持续累积**？（temporal_pressure）

做完这五个问题的判断，再查词典看基础等级，两者综合后给出最终信号评分。
